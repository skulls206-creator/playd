#1 - Music Streaming Web App
What & Why
Build a dark-themed music streaming web app where users can search for any song or artist, stream audio directly in the browser via an HTML5 player, see rich metadata (album art, artist, title), and optionally download the MP3. The backend uses Python's ytmdl library to search, match, and stream audio. The frontend is a React + Vite app with a polished "Now Playing" experience.

Done looks like
User types a song or artist name and hits search
Backend fetches metadata (cover art, album, artist) via ytmdl and streams the audio
A "Now Playing" card appears showing album art, track name, and artist
An HTML5 audio player lets the user play/pause/seek
A Download button saves the MP3 with full embedded metadata
The UI is dark-themed and minimalist
Out of scope
User accounts or playlists
Saving a library across sessions
Mobile app
Steps
Install system and Python dependencies — Install ffmpeg, python3, and ytmdl via pip in the Replit environment so the backend can process and stream audio.
Create the React frontend artifact — Scaffold a react-vite app at the root path (/) with dark theming and a search bar UI.
Add music API endpoints to the Express server — Add /api/music/search (returns metadata + stream URL), /api/music/stream (pipes audio bytes to the client), and /api/music/download (returns tagged MP3) endpoints, calling a Python helper script via child_process.
Write the Python ytmdl helper script — A small Python script that accepts a query, uses ytmdl's internal yt-dlp logic to resolve the YouTube source, fetches Apple Music/iTunes metadata, and writes or streams audio to stdout so the Express server can pipe it.
Build the frontend UI — Search bar, "Now Playing" card with album art, HTML5 audio player wired to the streaming endpoint, and a Download button.
Wire up search flow end-to-end — Connect the search bar to the backend, render metadata results, and load the stream URL into the audio player on selection.
